# For My Sweetheart 💗

A romantic, six-screen experience built with plain HTML, CSS, and JavaScript. No install, server, backend, or paid services are required.

## Run it

Open `index.html` in a modern browser, or open this folder in VS Code and use **Live Server** if you have that extension installed.

## Try the whole story

1. Tap or click the floating hearts to reveal their repeating messages.
2. Choose **Open my little world** and enter `11th` (capitalization and extra spaces are okay).
3. Say yes to the date invitation.
4. Pick today or a future date and submit it.
5. Answer the Saturday/Wednesday question. Choose **Yes, hai** to pick another date, or **No, nahi hai** to finish the story.
6. Use the restart button to return to the beginning and reset the interaction.

## Share it for free

The easiest option is GitHub Pages: create a repository, upload these four project files, then enable Pages in the repository's **Settings → Pages** section and select the main branch. The generated public URL can be shared. Netlify Drop is another free option: drag the project folder onto [Netlify Drop](https://app.netlify.com/drop) to publish it.

The password question is a playful client-side surprise, not real authentication.
